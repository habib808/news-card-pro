# Nahdah24 নিউজকার্ড জেনারেটর

প্রফেশনাল বাংলা নিউজকার্ড বানানোর টুল। দুটি পেজ আছে: `index.html` (PCD1) আর `d2.html` (PCD2)।

সুবিধাগুলো:
- আজকের টপ নিউজ, এক ট্যাপে কার্ড
- AI দিয়ে শিরোনামের ভেরিয়েশন
- শিরোনাম অনুযায়ী অনলাইন ছবি সাজেশন

## ফাইলগুলো

| ফাইল | কাজ |
|---|---|
| `index.html`, `d2.html` | কার্ড বানানোর দুই পেজ |
| `newsdesk.js` | টপ নিউজ, ভেরিয়েশন আর ছবি সাজেশনের প্যানেল |
| `api/index.js` | সার্ভারের কাজ: খবর সংগ্রহ ও র‍্যাঙ্কিং, ছবি আনা, AI (Vercel এটা নিজে চালায়) |
| `package.json`, `vercel.json` | Vercel-এর সেটিংস, এগুলো বদলানোর দরকার নেই |

**নিজে যোগ করবেন:** আপনার লোগো ফাইল `newslogo.png` (PCD1-এর জন্য) আর `width_150.webp` (PCD2-এর জন্য)। দুটোই রিপোর মূল ফোল্ডারে রাখবেন।

---

## ধাপ ১ — GitHub-এ আপলোড

1. github.com-এ লগইন করুন। উপরে ডানে **+** চাপুন, তারপর **New repository**।
2. নাম দিন, যেমন `nahdah24-newscard`। **Private** বেছে নিতে পারেন। তারপর **Create repository** চাপুন।
3. নতুন রিপোর পেজে **uploading an existing file** লিংকে ক্লিক করুন।
4. সব ফাইল আর **`api` ফোল্ডারসহ** ড্র্যাগ করে ছেড়ে দিন। লোগো ফাইল দুটোও দিন।
5. নিচে **Commit changes** চাপুন।

> ⚠️ API key কখনো GitHub-এ কোনো ফাইলে লিখবেন না। Key শুধু Vercel-এর সেটিংসে থাকবে (ধাপ ৩)।

## ধাপ ২ — Vercel-এ চালু করা (ফ্রি)

1. vercel.com-এ যান। **Sign Up** চাপুন, তারপর **Continue with GitHub**।
2. **Add New… → Project** চাপুন। আপনার রিপোর পাশে **Import** চাপুন।
   - রিপো তালিকায় না দেখালে **Adjust GitHub App Permissions** থেকে রিপোটিকে অনুমতি দিন।
3. কোনো সেটিং বদলাতে হবে না। **Deploy** চাপুন।
4. এক মিনিটের মধ্যে একটা লিংক পাবেন, যেমন `nahdah24-newscard.vercel.app`। এটাই আপনার সাইট।

## ধাপ ৩ — AI key যোগ করা (শিরোনাম ভেরিয়েশনের জন্য)

1. Vercel-এ প্রজেক্ট খুলুন। **Settings → Environment Variables**-এ যান।
2. **Key** ঘরে লিখুন `GEMINI_API_KEY`। **Value** ঘরে আপনার Gemini key দিন। তারপর **Save**।
3. **Deployments** ট্যাবে যান। সবচেয়ে উপরের ডিপ্লয়মেন্টের **⋯** মেনু থেকে **Redeploy** চাপুন।
   - নতুন key কাজ শুরু করতে এই redeploy লাগে।

ঐচ্ছিক আরও কিছু সেটিং:

| নাম | কী দেবেন |
|---|---|
| `PEXELS_API_KEY` | pexels.com/api থেকে ফ্রি key। আরও স্টক ছবি পাবেন। |
| `ACCESS_KEY` | যেকোনো পাসওয়ার্ড। অন্য কেউ আপনার AI কোটা খরচ করতে পারবে না। এটা দিলে `newsdesk.js` ফাইলের উপরের `const KEY = ''` এ একই পাসওয়ার্ড দিন। |
| `GEMINI_MODEL` | অন্য Gemini মডেল চাইলে। ডিফল্ট `gemini-flash-latest`। |
| `NEWS_FEEDS` | নিজের পছন্দের নিউজ ফিডের তালিকা (JSON)। যেমন: `[["প্রথম আলো","https://www.prothomalo.com/feed/",1.3]]` |

## পরে কিছু বদলাতে চাইলে

GitHub-এ ফাইল এডিট বা আপলোড করে **Commit** করুন। Vercel নিজে থেকেই ১ মিনিটের মধ্যে নতুন ভার্সন চালু করবে।

## সমস্যা হলে

- **টপ নিউজে "api পাওয়া যায়নি" দেখায়:** `api` ফোল্ডারটা রিপোর মূল ফোল্ডারে আছে কিনা দেখুন। থাকতে হবে `api/index.js` হিসেবে।
- **শিরোনামের নিচে "সাধারণ ভেরিয়েশন" দেখায়:** AI key কাজ করছে না। ধাপ ৩ আবার দেখুন, বিশেষ করে Redeploy করা হয়েছে কিনা।
- **কোনো নিউজ সাইটের খবর আসে না:** সাইটটি হয়তো তাদের RSS ঠিকানা বদলেছে। বাকি সাইটগুলোর খবর ঠিকই আসবে।
- **নিজের PHP হোস্টিং থাকলে:** আলাদা `api.php` ভার্সনও আছে। `newsdesk.js` দুটোই নিজে থেকে চিনে নেয়।
